# history-search

과거 세션에서 **발화를 찾아 지금 작업에 이어붙이는** 도구. 검색으로 끝나지 않고
매칭 발화를 전후 맥락과 함께 컨텍스트로 가져오는 것이 목적이다.

스크립트는 이 스킬 디렉토리 기준 `scripts/` 에 있다. Node 18+ 필요.

## 절차

### 1. 검색

```bash
node scripts/search.js "<쿼리>" [--all] [--days N] [--tools] [--top N]
```

출력은 세션별 한 줄 + 스니펫 2개 + **앵커**(`@<세션8자>#<라인>.<uuid8>`).

### 2. 사용자에게 확인

검색 결과를 보여주고 **어느 것을 가져올지 물어본다.** 결과 전체를 임의로
픽업하지 말 것 — 픽업은 컨텍스트를 먹는다.

사용자가 "1번 3번" 처럼 번호로 답하면, 검색 출력에 적힌 해당 앵커를 쓴다.
번호는 그 출력 안에서만 의미가 있으므로 항상 앵커로 변환해 호출한다.

### 3. 픽업

```bash
node scripts/pick.js <앵커...> [--ctx N] [--tool tN]
```

여러 앵커를 한 번에 줄 수 있다. 출력이 그대로 컨텍스트가 되므로, 받은 내용을
사용자에게 통째로 되뿌리지 말고 **질문에 답하는 데 쓴다.**

### 4. 필요하면 세션 통째로 이어받기

검색 출력의 `claude -r <세션ID>` 를 사용자에게 안내한다. 직접 실행하지 말 것
(현재 세션을 대체하는 동작이다).

## 옵션

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--all` | off | 전체 프로젝트. 기본은 현재 프로젝트 + 하위 |
| `--days N` | 무제한 | 최근 N일 (파일 mtime = 세션 마지막 활동) |
| `--tools` | off | 툴 설명·결과까지 검색 대상에 포함 |
| `--top N` | 8 | 표시할 세션 수 |
| `--ctx N` | 3 | 픽업 시 매칭 발화 전후 턴 수 |
| `--tool tN` | — | 픽업 출력에 `[tN]` 으로 요약된 툴의 결과 전문 |

## 판단 기준

- **범위**: 지금 작업 중인 프로젝트 얘기면 기본값 그대로. 다른 프로젝트에서 한
  얘기이거나 기본 범위에서 안 나오면 `--all`.
- **`--tools`**: 사람 발화가 아니라 "그때 그 쿼리 결과" / "그 파일 내용" 을 찾을 때만.
  켜면 노이즈가 크게 는다.
- **`--ctx`**: 결론만 필요하면 1~2, 논의 흐름이 필요하면 4~6. 기본 3.
- **툴 전문**: 요약 한 줄로 부족할 때만 `--tool`. 결과가 수백 행일 수 있다.

## 주의

- 검색은 **부분일치**다. 정규식이 아니고, 줄바꿈이나 따옴표가 든 문구는 1패스에서
  놓칠 수 있다. 짧은 특징적 어구로 검색할 것.
- 기본 검색 대상은 user/assistant 발화뿐이다. 훅 출력, `<system-reminder>`,
  attachment, 툴 결과는 제외된다.
- **리텐션**: `cleanupPeriodDays` 기본값이 30일이라 오래된 세션은 이미 사라졌을 수
  있다. 검색 결과가 0이고 사용자가 "분명히 했었는데" 라고 하면 이 가능성을 알린다.
- 검색 결과가 0일 때 조용히 `--all` 로 범위를 넓혀 재실행하지 말 것. 사용자에게
  알리고 확인받는다.
