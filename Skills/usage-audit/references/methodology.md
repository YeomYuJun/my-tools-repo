# usage-audit — 측정 방법과 한계

## 토큰 환산 비율

`CHARS_PER_TOKEN = 3.35`

추정치가 아니라 실측 보정값이다. 한 세션에서 MCP 서버들이 비동기로 연결되며 도구가 116개 추가될 때,
요청 바이트가 150,170 chars 늘고 API가 보고한 토큰이 45,457 늘었다. 150,170 / 45,457 ≈ 3.30이며,
그중 메시지 증분(약 650 토큰)을 제외하면 약 3.35다.

흔히 쓰는 4.0 chars/token은 산문 기준이라 **도구 스키마 JSON에는 과소 추정**이 된다.
JSON은 구두점·따옴표 밀도가 높아 토큰당 문자 수가 적다.

## 각 수치의 출처

| 수치 | 출처 |
|---|---|
| MCP 서버 목록 | `~/.claude.json` 의 `mcpServers` 키 |
| 스킬 목록·설명 길이 | `~/.claude/skills/*/SKILL.md` 의 frontmatter |
| 서브에이전트 | `~/.claude/agents/*.md` 의 frontmatter |
| 훅 | `~/.claude/settings.json` 의 `hooks` |
| 플러그인 활성 상태 | `settings.json` 의 `enabledPlugins` |
| 스킬/플러그인 사용 횟수 | `~/.claude.json` 의 `skillUsage`, `pluginUsage` (하니스가 유지) |
| MCP 도구 실사용 | 세션 JSONL의 `assistant` 레코드에서 `tool_use` 중 `mcp__` 접두사 집계 |
| 도구 오류 | 세션 JSONL의 `user` 레코드에서 `tool_result.is_error === true` |
| 요청 바이트 구성 | `probe.js` 의 와이어 캡처 (선택 단계) |

## 오류율 정규화

세션마다 길이가 다르므로 각 레코드의 **세션 내 정규화 위치**(0~1)를 구해 4분면으로 나눈다.
사분면별 오류 수를 **같은 사분면의 `tool_use` 호출 수**로 나눠 오류율을 낸다.

이 정규화가 중요한 이유: 정규화 없이 오류 건수만 보면 "후반에 일을 더 많이 해서 오류도 많다"와
"같은 양의 일이 후반에 더 자주 실패한다"를 구분할 수 없다. 실제 측정에서 사분면별 호출량은
거의 평평했고(1336/1444/1397/1212) 오류율만 2.25% → 4.21%로 올랐다.

## 오류 분류기

`classifyError()`는 정규식 기반이며 완전하지 않다. 미분류는 `OTHER`로 떨어진다.
실측에서 `OTHER`는 전체의 약 20%였다. 분류 결과를 절대적으로 신뢰하지 말고
경향 파악용으로 쓸 것.

`USER_REJECTED`는 오류로 집계되지만 **실패가 아니다** — 사용자가 도구 호출을 거부한 것이며
권한 게이트가 의도대로 작동한 흔적이다. 리포트 해석 시 분리해서 봐야 한다.

## 와이어 프로브의 동작과 한계

`probe.js`는 임시 로컬 리버스 프록시(포트 0 = OS 할당)를 띄우고,
`ANTHROPIC_BASE_URL`을 그 주소로 지정한 `claude -p` 한 번을 통과시킨다.
클라이언트↔프록시 구간만 평문(루프백)이고 프록시↔API는 정상 TLS다.

- **2턴을 강제한다.** 프롬프트가 bash 호출을 유발하므로 turn 2가 발생한다.
  turn 1만 재면 아직 연결되지 않은 MCP 서버가 빠져 **도구 수가 과소 집계**된다
  (cold-start 경쟁: 첫 요청 발사와 MCP 연결 완료가 경주한다).
- **인증 토큰이 캡처에 포함된다.** 그래서 원본 버퍼는 메모리에서만 쓰고 집계 수치만 저장한다.
  `--keep-raw`를 쓰지 않는 한 디스크에 남지 않는다.
- **`-p` 모드 기준이다.** 대화형 세션은 지연 로딩(deferred tools / ToolSearch)을 쓸 수 있어
  도구 구성이 다를 수 있다. 프로브 수치는 "이 모드에서의 상한"에 가깝다.
- 도구 집합은 실행마다 흔들린다(cold-start 경쟁). 정밀한 비교가 필요하면 여러 번 돌려 분포를 볼 것.

## 알려진 한계

1. **"사용 0회"는 이 로그 범위 내의 사실**이다. 최근 도입했거나 특정 프로젝트 전용 서버일 수 있다.
2. **서브에이전트 트랜스크립트는 집계에서 제외**된다(세션 디렉토리 최상위 `.jsonl`만 스캔).
   서브에이전트가 쓴 MCP 도구는 사용 횟수에 반영되지 않아 과소 집계될 수 있다.
3. **claude.ai 커넥터**(Notion 등)는 로컬 `mcpServers`에 없어서 설정 목록에는 안 잡히지만
   와이어 프로브에는 잡힌다. `external_mcp` 발견 항목으로 표시된다.
4. **비용 환산은 토큰까지만** 한다. 실제 금액은 모델·요금제에 따라 다르므로 계산하지 않는다.
   비교가 필요하면 `input×1.0 + cache_read×0.1 + cache_create×2.0`(1h TTL 기준) 가중치를 쓸 것.
5. 캐시 동작상 **도구 배열은 직렬화 위치 0**이라, 세션 중 도구가 추가되면 그 이후 캐시가 전부
   무효화된다. 서버를 줄이면 블록 크기뿐 아니라 이 cold-start 전멸까지 함께 사라진다.
